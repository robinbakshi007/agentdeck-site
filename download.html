Download AgentDeck

AgentDeck connects Antigravity on your computer to the AgentDeck app on your phone. Pick one way to install it.

Already installed AgentDeck on this computer? Your pairing code is made by AgentDeck itself, not by this website.

Show my pairing code

Open this on the computer where AgentDeck is installed. On a Mac you can also click the AgentDeck menu-bar icon → Pair a phone…

Recommended: inside Antigravity

Like Antigravity's own Remote Control, AgentDeck can run inside Antigravity: nothing else to install, and it works on Mac (Apple silicon and Intel), Windows and Linux.

Download the Antigravity extension
  1. In Antigravity, open Extensions (⇧⌘X on Mac, Ctrl+Shift+X on Windows/Linux).
  2. Click the ··· menu at the top of the Extensions panel → Install from VSIX… → choose agentdeck-1.2.5.vsix.
  3. A Pair your phone tab opens: scan it with the AgentDeck app. Later: the AgentDeck item in the status bar.

AgentDeck then runs whenever Antigravity is open (which is when your agents work). Prefer it always on? Use the Mac or Windows app below instead; they work together.

Mac

Apple silicon and Intel Macs, macOS 13 or later.

Download for Mac

Open the file, drag AgentDeck into Applications, open it. Mac setup help

Windows

Windows 10 or 11, 64-bit.

Download for Windows
  1. Double-click AgentDeck.exe. It installs for your user account (no admin needed), starts with Windows and opens the pairing page.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway (this goes away once our signed build ships).
  3. On your phone, scan the code or type the 8 characters.

Pair another phone later: open http://localhost:48632/pair. Remove AgentDeck: run %LOCALAPPDATA%\AgentDeck\AgentDeck.exe uninstall.

Linux

Needs Node.js 20 or newer. In a terminal: curl -fsSL https://agentdeck.finnova.com.au/install.sh | sh (details)
