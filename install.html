Install the AgentDeck host

On a Mac with Apple silicon? Get the AgentDeck Mac app instead: no Terminal or Node.js needed.

For Intel Macs, Linux and Windows, the host is a small background program that needs Node.js 20+.

Mac or Linux: open Terminal and run:

curl -fsSL https://agentdeck.finnova.com.au/install.sh | sh

It downloads one file to ~/.agentdeck/bin, checks its checksum, and starts it at login.

Windows: download agentdeck-host.cjs, then in PowerShell run node agentdeck-host.cjs install.

Pair your phone

  1. Open Antigravity.
  2. The installer opens the pairing page for you (you can reopen it any time at http://localhost:48632/pair on that computer).
  3. In the AgentDeck app, tap Scan pairing code, or Enter code instead and type the 8 characters. Your phone doesn't need to be on the same Wi-Fi.

Uninstall

node ~/.agentdeck/bin/agentdeck-host.cjs uninstall then delete ~/.agentdeck.
