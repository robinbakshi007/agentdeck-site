Install the AgentDeck host

The host is a small background program that connects your phone to Antigravity on your computer. It needs Node.js 20+.

Mac or Linux: open Terminal and run:

curl -fsSL https://robinbakshi007.github.io/agentdeck-site/install.sh | sh

It downloads one file to ~/.agentdeck/bin, checks its checksum, and starts it at login.

Windows: download agentdeck-host.cjs, then in PowerShell run node agentdeck-host.cjs install.

Pair your phone

  1. Open Antigravity.
  2. Visit http://localhost:48632 on the computer and tap Show pairing code.
  3. In the AgentDeck app, tap Scan pairing code.

Uninstall

node ~/.agentdeck/bin/agentdeck-host.cjs uninstall then delete ~/.agentdeck.
