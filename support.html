Common fixes

  • "Could not reach your Mac": make sure the phone and computer are on the same Wi-Fi (guest networks often block devices from seeing each other), and that the host is running: open http://localhost:48632 on the computer.
  • Works on Wi-Fi only: on the host dashboard, check that Remote access is on, then pair the phone again so it learns the relay address.
  • "Antigravity isn't running": open Antigravity on the computer. The host finds it automatically.
  • No approval prompts appear: Antigravity only asks for approval when its terminal policy is set to request review; with auto-run, commands run without asking.
  • Restore a subscription: Settings → Restore purchases.
